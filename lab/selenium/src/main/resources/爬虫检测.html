检测方法说明

Selenium、Puppeteer等自动化工具会在浏览器中留下可检测的痕迹，以下是本工具使用的检测方法：

基础检测方法 (检测明显的自动化特征)

1. WebDriver 属性检测

自动化浏览器通常会在 navigator.webdriver 属性中返回 true，而普通浏览器返回 undefined 或 false。

2. 插件列表检测

自动化浏览器可能：返回空的插件列表、缺少常见的浏览器插件、插件列表包含自动化工具特有的项目。

3. 窗口属性检测

Selenium会在window对象上添加属性如：_Selenium_IDE_Recorder、callPhantom、__webdriver_script_fn等。

4. 权限检测

检查浏览器是否支持某些功能，或权限状态是否异常：检查Notification权限、检测Chrome自动化扩展、检查浏览器驱动特征。

高级检测方法 (检测隐藏的自动化特征)

1. Chrome DevTools Protocol检测

检测CDP连接痕迹，这是大多数自动化工具使用的底层协议。

2. DOM API补丁检测

自动化工具经常重写DOM API来隐藏自己，检测这些修改可以识别自动化。

3. WebGL供应商检测

自动化环境通常使用虚拟GPU如 LLVMPipe、SwiftShader，而真实浏览器使用硬件GPU。

4. iframe沙箱检测

自动化工具可能不会正确实现iframe的隔离，通过检测iframe异常行为识别自动化。

行为检测方法 (分析用户交互模式)

1. 鼠标移动模式分析

人类鼠标移动有自然的曲线和随机变化，而自动化工具通常产生直线或过于规律的移动。

2. AudioContext检测

自动化浏览器可能没有正确的AudioContext实现或实现不完整。

3. Chrome运行时检测

检测自动化浏览器特有的Chrome运行时特征，如特定的扩展ID或配置。

4. 交互模式检测

通过分析点击间隔、点击位置等交互模式识别自动化脚本。

如何避免被检测？

自动化工具可以通过以下方式尝试规避检测：

  • 使用无头浏览器检测规避插件
  • 修改WebDriver标志（ChromeOptions）
  • 模拟人类鼠标移动和点击模式
  • 随机化请求间隔和浏览行为
  • 使用真实浏览器的用户代理和插件配置
  • 禁用自动化扩展特征

注意：随着检测技术发展，完全规避检测变得越来越困难。
